# `> engineering.principles`

```text
01  Clean architecture over clever code
02  Understand before implementing
03  Validate at the boundary
04  Keep controllers thin
05  Put business logic in services
06  Keep persistence concerns in repositories
07  Use DTOs where they make the API safer
08  Handle errors intentionally
09  Test behaviour, not implementation details
10  Document APIs before someone has to guess
```
