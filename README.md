# ⟡ SOFTWARE ENGINEERING MINDSET

> Understand the problem before writing the solution.

> Keep business logic out of controllers.

> Test the failure path, not only the happy path.

> A successful request does not automatically mean a good design.

> Debugging is part of engineering, not a punishment for engineering.
